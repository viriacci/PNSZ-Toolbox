# Dokumentacja PNSZ Toolbox v1.0.0

Główny opis projektu znajduje się w `../README.md`.

W tym katalogu są:

- `CHANGELOG.md` — zakres pierwszego wydania,
- `CODE_AUDIT.md` — wynik czyszczenia i kontroli kodu,
- `SIGNATURE_INFO.txt` — dane certyfikatu, hashe i wynik lokalnej kontroli podpisu,
- `SIGNING.md` — zasady obsługi self-signed Code Signing.
